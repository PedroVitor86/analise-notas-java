# 📊 Sistema de Análise de Notas da Turma

Um programa em Java desenvolvido para realizar o processamento e a análise estatística das notas de uma turma de alunos de forma totalmente dinâmica.

Este projeto foi construído como prática do **Bloco 1.4: Estruturas de Dados Básicas**, consolidando o aprendizado sobre **Arrays Unidimensionais (Vetores)**, laços de repetição e manipulação de dados com o `Scanner`.

---

## 🚀 Funcionalidades

- 📏 **Tamanho Dinâmico**: Pergunta a quantidade de alunos e instancia o Array com o tamanho exato na memória.
- 📝 **Entrada de Dados**: Coleta e armazena a nota de cada aluno via terminal utilizando `java.util.Scanner`.
- 📋 **Relatório Completo**: Exibe a lista formatada de todas as notas cadastradas.
- 🧮 **Média da Turma**: Acumula a soma de todas as notas e calcula a média aritmética.
- 🏆 **Maior e Menor Nota**: Percorre o Array utilizando estruturas condicionais (`if`) para encontrar e exibir a maior e a menor nota da turma.

---

## 🛠️ Tecnologias e Conceitos Utilizados

- **Linguagem**: Java (JDK 17+)
- **Entrada/Saída**: `java.util.Scanner`
- **Estruturas de Dados**: Arrays Unidimensionais (`double[]`)
- **Controle de Fluxo**: Laços de repetição (`for`), propriedade `.length` e condicionais (`if`).

## 🎓 Conceitos Aplicados

* Alocação dinâmica de Arrays com a palavra-chave `new`.
